

## Information Management Group Project

This project is an **Enterprise Resource Planning (ERP) System**
developed as a group project for the **Information Management** course.

The project focuses on developing essential user authentication features
and integrating a functional database using **Supabase**.

------------------------------------------------------------------------

## Project Goals

The main goals of the project are:

1.  **Login Page**\
    Develop a functional login page where registered users can access
    the system.

2.  **Set and Reset Password**\
    Allow users to set their password and reset it when necessary.

3.  **User Registration**\
    Provide a registration feature for creating new user accounts.

4.  **Main Landing Page**\
    Redirect users to the main landing page after a successful login.

5.  **Database Integration**\
    Connect the system to a working **Supabase database**.
