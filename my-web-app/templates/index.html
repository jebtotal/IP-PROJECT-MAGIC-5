RBAC Governance

Role-based access control keeps every module and action accountable.

Superadmin

Full system access. Manages every module and assigns roles to any user.

Admin

Manages most modules and user rights, except Superadmin accounts.

User

Works only in the modules and actions (view, add, edit, delete) granted by an Admin.

Deletes are soft deletes with an audit trail, so records stay recoverable.

About PentadERP

PentadERP is an Enterprise Resource Planning web system built for an Information Management project. It brings Customers, Products, Human Resources, Sales, and Reports into one platform, with role-based access so each user only sees and does what they are permitted to.
